# 保留中のパッチ

前提条件が揃うまで適用しない実装を置く。

## d1-direct-chaining.patch

**段 D-1 (ランナー内ディスパッチループ)。実装・検証済みだが、
現状では効かないので適用していない。**

実機で測った結果、予測 +4.3% に対し **実測 -2.47%** (9072 → 8848 kHz)。

### 効かなかった理由 (機構は正しく動いていた)

チェーン長は、実際にブロックを走らせた呼び出しの中では **3.533** で、
これは **1/(1 - 0.717) と厳密に一致**する。f = 0.717 の実測どおりに
命中していた。

問題は **arena が満杯 (16356/16384、1432 ブロック)** なので、
**`run()` 呼び出しの 69% がブロックを 1 本も実行しない**こと。
それらはループのコストだけ払って何も回収しない。

- 回収: 1,817,933 hop × 43 = ホストサイクルの **0.54%**
- 追加コスト: `run()` 1 回あたり **22.8 サイクル** → 約 **3.0%**

### 適用してよくなる条件

**arena が溢れなくなること。** そうなれば 69% の空振りが実行を伴う
呼び出しに変わり、チェーン長が 3.53 になって、D-1 は当初の予測どおり
**約 +4.3%** を回収する。

具体的には `満杯で諦めた` が `落とした` の大半を占めなくなった時点。

### 中身

- `run()` のループ化、`chainStop()` (純関数)、budget の配線
- テスト 13 件 (同値性・割り込み受理・budget・チェーン中の自己無効化・
  miss で break・pull 型の回帰)
- 変異 12 件すべてが落ちることを確認済み
- ホスト専用の `runBlock` フック (hop 2 本目以降をホストで検査するため)
